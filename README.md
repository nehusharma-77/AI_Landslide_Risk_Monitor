# 🌍 AI Landslide Risk Monitor

A machine learning project that estimates landslide risk using environmental parameters.

## 📌 Project Overview

This project uses a Random Forest machine learning model to predict landslide risk based on environmental conditions.

## 🌱 Input Parameters

The model uses:

- Rainfall
- Soil Moisture
- Temperature
- Humidity
- Soil Tilt

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest
- Streamlit
- Joblib

## ✨ Features

- Machine learning-based risk prediction
- Interactive Streamlit interface
- LOW / MEDIUM / HIGH risk display
- Simple and user-friendly dashboard
